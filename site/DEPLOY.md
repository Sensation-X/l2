# Деплой сайта «Хурмыч» — под твой сервер (Beget VPS)

Дано: VPS Beget «Intrepid Aris» (Ubuntu, SPB), root-доступ, IP **31.207.75.248**, 2 ядра / 2 ГБ / 30 ГБ NVMe. Домен **hurmych.ru** куплен на год. Сайт — чистая статика, такому серверу её хватит с многократным запасом.

Порядок: **DNS → заливка файлов → скрипт деплоя → проверка → поисковики**.

---

## Шаг 1. Направь домен на сервер (DNS)

Сейчас `hurmych.ru` никуда не указывает (проверено 12.09.2026). В панели Beget:

1. Раздел **«Домены и DNS»** → выбери `hurmych.ru` → **«Управление DNS-записями»**.
2. Добавь две записи:

| Тип | Имя (хост) | Значение |
|---|---|---|
| A | `@` (пусто / hurmych.ru) | `31.207.75.248` |
| A | `www` | `31.207.75.248` |

3. Сохрани. Расхождение по миру — от 5 минут до часа.
4. Проверь с ПК: `nslookup hurmych.ru` — должен вернуться `31.207.75.248`.

## Шаг 2. Залей файлы и запусти деплой

Сайт уже собран с правильным доменом (`SITE_URL = https://hurmych.ru`). Из PowerShell в папке `D:\L2_media`:

```powershell
scp -r site\dist root@31.207.75.248:/root/site_dist
scp site\deploy_server.sh root@31.207.75.248:/root/
ssh root@31.207.75.248
```

Уже на сервере:

```bash
bash /root/deploy_server.sh твоя@почта.ru
```

Скрипт сам поставит nginx и certbot, разложит сайт в `/var/www/hurmych`, включит конфиг, выпустит HTTPS-сертификат Let's Encrypt и настроит редирект с http на https. Почта нужна только для уведомлений об истечении сертификата (продлевается автоматически).

Если сертификат не выпустился (DNS ещё не разошёлся) — сайт уже работает по `http://hurmych.ru`; повтори позже:
```bash
certbot --nginx -d hurmych.ru -d www.hurmych.ru
```

## Шаг 3. Проверка

- `https://hurmych.ru` — главная с таймерами.
- `https://hurmych.ru/guides.html`, `/updates.html`, `/start.html`, `/about.html`.
- `https://hurmych.ru/rss.xml` и `/sitemap.xml` открываются.
- Мобильная версия и скорость: статика без тяжёлых скриптов, PageSpeed обычно 90+.

## Шаг 4. Поисковики

1. **Яндекс.Вебмастер**: добавь `https://hurmych.ru`, подтверди права мета-тегом или файлом, укажи `sitemap.xml`.
2. **Google Search Console**: то же самое.
3. Поставь ссылку на сайт в описания Telegram-канала и YouTube, в закреп первого поста.

## Обновление контента (регулярно)

1. Новые/правленые markdown кладутся в `site/content/` (обычно это делаю я).
2. `python3 site/build_site.py`
3. `scp -r site\dist\* root@31.207.75.248:/var/www/hurmych/`

Новые статьи автоматически попадают на главную, в RSS и sitemap.

## Реферальная ссылка (когда выдаст партнёрка)

В `site/build_site.py` замени константу `REF_LINK = "#REF#"` на свою ссылку, пересобери и обнови файлы на сервере. Кнопка «Создать аккаунт и забрать бонусы» появится на главной и в каждой статье.

## Гигиена безопасности сервера (сделай на этой неделе)

- Смени пароль root после первого входа: `passwd`.
- Лучше — вход по SSH-ключу и запрет пароля: правка `/etc/ssh/sshd_config` (`PasswordAuthentication no`) после проверки ключа.
- Не публикуй скриншоты панели с реквизитами и балансом: IP публичный — это норма, а вот доступы к панели должны оставаться только у тебя.
- Держи баланс VPS положительным: при нуле сервер остановится вместе с сайтом. На скриншоте 328 ₽ / 11 дней — поставь автоплатёж или напоминание.
- Продление домена: включи автопродление в Beget, чтобы сайт не упал через год из-за забытой оплаты.

## Если захочешь другой хостинг (запасные инструкции)

**Shared с панелью:** загрузи содержимое `site/dist/` в `public_html` через файловый менеджер или FTP, включи Let's Encrypt в панели.

**Другой VPS:** тот же `deploy_server.sh` — он не привязан к Beget, нужны только Ubuntu/Debian и root.
